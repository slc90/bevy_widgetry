# 设计阅读入口

设计文档解释系统为什么这样构成，以及状态、结构和生命周期由谁负责。使用代码、参数和操作示例放在 [功能说明](../features/README.md)。

## 先建立整体认识

[Widgetry 整体设计](architecture.md) 从 Bevy 运行模型出发，逐步说明独立模块、共享机制、行为与视觉组合，以及 Facade 与应用的边界。

## 再进入具体能力

[模块设计目录](modules/README.md) 按控件与基础能力定位。各篇围绕自己的核心问题展开，不使用统一的章节模板：数值控件关心正式值和编辑状态，数据视图关心身份与投影，窗口能力关心原生对象和资源归属。

## 跨越模块时理解共同协议

[机制设计目录](mechanisms/README.md) 解释同一规则怎样被多个模块共同使用。模块文档只保留理解本模块必需的关系，通用的禁用、输入和诊断协议在机制页中展开。

例如，Button 说明 Loading 与默认 Style 为什么分开；Disabled 说明内部理由怎样与祖先及显式请求组合。两篇共同解释设计，但不重复列出全部 API。
