## FileDialog 图标

导航和搜索 SVG 取自 [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons/tree/9bfae3d782fda4c8764f2128cec4d0dda160b283/assets) 的 20 Regular：Arrow Left、Arrow Right、Arrow Up、Arrow Clockwise、Search。仅将路径填色替换为白色，供 Widgetry 前景色栅格化使用。

- 来源版本：`9bfae3d782fda4c8764f2128cec4d0dda160b283`
- 随附许可证：`FluentUI-MIT.txt`
