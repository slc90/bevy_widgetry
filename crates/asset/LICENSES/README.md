# 内建字体来源

`SmileySans-Oblique.ttf` 使用 Smiley Sans / 得意黑 v2.0.1 官方发布包中的未修改字体。

- 发布页：https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1
- 发布包：https://github.com/atelier-anchor/smiley-sans/releases/download/v2.0.1/smiley-sans-v2.0.1.zip
- 原始许可证：https://github.com/atelier-anchor/smiley-sans/blob/v2.0.1/LICENSE
- 随附许可证：`SmileySans-OFL-1.1.txt`

## FileDialog 图标

导航和搜索 SVG 取自 [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons/tree/9bfae3d782fda4c8764f2128cec4d0dda160b283/assets) 的 20 Regular：Arrow Left、Arrow Right、Arrow Up、Arrow Clockwise、Search。仅将路径填色替换为白色，供 Widgetry 前景色栅格化使用。

- 来源版本：`9bfae3d782fda4c8764f2128cec4d0dda160b283`
- 随附许可证：`FluentUI-MIT.txt`
