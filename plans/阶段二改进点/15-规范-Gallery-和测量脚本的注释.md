# 规范 Gallery 和测量脚本的注释

## 目标与范围

处理 Gallery 页面、国际化、素材、启动与 Benchmark 支持代码，以及相关 Python／配置说明中的代码注释。

## 修改设计

例如 `gallery/src/i18n.rs` 防止正文同名文本被误判为标题的原因、FileDialog 页面关于延迟 Native Window 回收的原因，都应作为实际约束保留或在对应实现已被替换后准确更新。不要把待删除的脆弱实现注释移到新语义接口旁，形成过时说明。

既有英文 Python Docstring 和测量边界说明有价值时保留；普通职责说明、重复的测试断言解释和无意义步骤注释删除。所有保留的代码／配置注释按英文和独立行规则处理。国际化中英文翻译、中文日志、文件路径与用户可见文本保持原样。

Gallery 不强制为纯注释改动新增单元或集成测试，也不需要用 BRP 验证没有被改动的交互。若修改意外涉及行为，应归回对应功能增量而不是藏在此项中。

## 完成条件

没有翻译业务字符串，没有修改测量时间边界或脚本协议。对实际原因的说明正确且必要，纯文本整理不被包装为已验证的 GUI 或性能改进。

## 预期产出

与 Gallery 实际实现和测量口径一致的注释。
