# 清理库入口和 Gallery 入口的重复功能说明

## 目标与范围

清理各库 `src/lib.rs` 和 `gallery/src/main.rs` 顶部已经由 `docs/crates/`、`docs/gallery.md` 承载的功能概述、职责列表、使用边界和重复介绍。内部日志入口按重命名后的目录处理。

## 修改设计

已生成独立文档不等于源码头部已经清理。Core、Tree、Facade、app_logging、app_icon_build、test_utils 等入口仍有成段中文功能说明；它们与集中说明形成两份维护来源。

逐段核对对应 Markdown。已经完整承载的概述直接删除；若发现仍有独立价值的约束，先确定它是公开契约还是局部实现陷阱：公开契约补入对应功能文档，局部非显然原因保留在真正相关的代码位置，并使用英文。不要为了删除文件头而丢失错误处理、资源所有权或输入边界。

本项不机械删除所有 Rustdoc，也不把重复介绍整体翻译成英文后继续放在入口。平台 `compile_error!`、模块声明、导出、Plugin 装配与代码行为保持不动。

## 完成条件

每个已处理入口只有真正必要的源码说明，集中功能文档没有因删除而丢失独有契约。Diff 不包含业务实现、测试断言或 API 的意外变动；纯注释整理不要求新增行为测试。保留仍有实际用途的文档测试或示例，不以删头部为由删除它们。

## 预期产出

不再与集中功能文档重复维护的库入口和 Gallery 入口。
