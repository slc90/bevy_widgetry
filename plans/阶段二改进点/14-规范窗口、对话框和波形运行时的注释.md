# 规范窗口、对话框和波形运行时的注释

## 目标与范围

处理 Window、MessageBox、FileDialog、Waveform 的生产代码、测试与 Benchmark 注释，不改变其业务或运行机制。

## 修改设计

保留并翻译资源回收阶段、Modal 输入归属、IME 路由、异步 Session／Token、编辑器 Tab stop、Raw Buffer 事务提交和 staging 容量释放等非显然原因。`crates/file_dialog/src/style.rs::sync_tab_stop` 和 `crates/waveform/src/runtime.rs` 的相关中文说明属于这种情况。

删除已由代码表达的职责介绍、固定的断言说明和过时的历史实现描述；必要原因不移动到不相关的文件头。独立句子独立成行，不使用行尾注释。中文日志、错误信息、可见文案与路径字符串不是此次翻译对象。

不能借清理改动 Worker 架构、取消语义、Owned／Borrowed 生命周期、波形读失败重试或 Stats。对 API 边界的有效说明应与对应 `docs/crates/` 保持一致，但不重写整份功能文档。

## 完成条件

Diff 只包含注释和确有必要的说明同步；缓冲区、Session、输入和 Native Window 行为没有混入改动。关键时序和内存原因保留，普通说明不机械翻译保留。

## 预期产出

准确解释运行时特殊约束、同时符合注释规范的相关源码。
