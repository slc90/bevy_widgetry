# 增加正多边形、星形与圆弧工具

## 目标

提供可调参数的常用几何绘制工具，并将生成结果统一转换为
`CanvasPath`，使其继续使用现有 Path 编辑、选择、变换和导出能力。

## 正多边形

正多边形工具支持边数与半径。Pointer
操作确定中心和外接半径；边数通过工具参数设置，最少为
3。顶点按固定起始角生成，确保相同参数得到确定结果。Shift
约束只影响角度吸附，不改变多边形数据模型。

## 星形

星形工具支持角数、外半径和内外半径比例。角数至少为
3；内外半径比例必须大于 0 且小于
1。生成的顶点按外半径、内半径交替排列，并闭合为
Path。预览应与最终提交使用相同参数生成函数，避免预览与落盘形状不一致。

## 圆弧

圆弧工具通过起点、终点、半径、弧轴旋转和弧方向生成现有
`CanvasPathCommand::ArcTo`。工具需要提供可理解的拖动手势和参数控制；无效半径、重合端点或退化参数应拒绝提交，而不是生成不可见或自相交的错误结果。

## 统一工具生命周期

三种工具都使用 View 级草稿和现有 Pointer Capture
生命周期。完成时才创建正式 Path 并记录一个 Undo
条目；取消时清理草稿，不产生历史。所有参数验证放在 Path
提交前完成，失败不留下部分 Item。

## 完成条件与验证

-   正多边形边数边界、旋转角和半径计算有确定性测试。
-   星形角数、内外半径比例及退化参数有测试。
-   ArcTo 的半径、旋转、large-arc 和 sweep 参数正确。
-   预览和提交使用相同几何生成逻辑。
-   生成 Path 可以继续节点编辑、变换、复制和导出。
-   取消不修改 Document；成功创建可 Undo/Redo。
-   更新 Coverage Model、Canvas 功能文档和设计文档。
-   Gallery 通过 BRP 验证参数修改、预览和提交。

## 设计边界

不为正多边形、星形或圆弧增加独立 `CanvasGeometry` 类型；它们都是 Path
构造工具。
