# 增加对象吸附与智能参考线

## 目标

在网格吸附之外，增加对象边缘、中心和 Path
节点吸附，并在拖动时显示智能参考线，帮助用户排列图标、流程图节点和插画部件。

## 吸附目标

对象吸附候选来自当前 Document 中可见的 Item： - Shape
的变换后边界左/右/上/下边缘与中心线。 - Group 的聚合边界边缘与中心线。 -
Path 的锚点/端点位置。

当前选择集合中的 Item 不作为自身吸附目标。隐藏 Layer 的 Item
不参与吸附；锁定但可见的 Item 可以作为只读参考目标，不能被吸附操作修改。

对象边界统一使用 Document-space AABB。旋转对象先将局部边界变换到
Document 坐标，再计算 AABB；该规则同时用于智能参考线和对齐功能。

## 智能参考线

当被拖动 Item 的边缘或中心与另一个 Item 的对应边缘/中心对齐时，View
显示临时参考线。若两个 Item
之间出现等间距关系，可显示距离提示。参考线只表达当前对齐关系，不修改未选中的对象。

吸附容差使用屏幕逻辑像素，并根据 Zoom 换算到 Document 坐标。默认容差为 8
个逻辑像素，可由 View
配置调整。候选选择按距离优先；距离相同时按目标绘制顺序和稳定 Entity
顺序确定，避免 Pointer
轻微抖动导致目标反复切换。拖动期间保留当前候选的轻微滞回，减少闪烁。

## 与网格吸附的优先级

用户显式捕捉到 Path 节点或后续 Connector Anchor
时优先于普通对象边缘；普通对象边缘/中心优先于网格交点。每种吸附来源可单独启用。程序化
API 不执行吸附。

## 完成条件与验证

-   Shape 边缘/中心、Group 边界和 Path 节点吸附有确定性测试。
-   隐藏 Item 不作为目标；锁定但可见 Item 可以作为只读目标。
-   当前选择集合不吸附到自身。
-   8 px 容差随 Zoom 正确换算，且可配置。
-   多个候选目标的选择稳定，拖动时无明显抖动。
-   智能参考线只在相关操作期间出现，结束/取消后清理。
-   两个 View 的吸附设置和参考线互相独立。
-   更新 Coverage Model、Canvas 功能文档和设计文档。
-   Gallery 通过 BRP 验证对象边缘/中心吸附、Path 节点吸附和参考线显示。

## 设计边界

不实现曲线切线吸附、任意交点求解、角度约束、持久辅助线或自动布局。Connector
Anchor 吸附在 Connector 锚定增量中加入。
