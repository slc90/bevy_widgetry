# Gallery：用 Canvas 创建流程图与结构图

## 目标

增加流程图演示，验证 Canvas
能够表达节点、连接关系、文字标签和有序结构，而不只是自由摆放几何图形。

## 演示内容

初始流程图包含开始/结束、处理、判断、输入输出、数据库和文档节点。节点使用流程图
Shape 预设，节点标题使用 CanvasText，节点之间使用
CanvasConnector，包含直线/折线、箭头和标签。

用户能够： - 创建、移动、复制和删除流程节点。 - 将 Connector
端点吸附到节点锚点。 - 移动节点时观察连接线自动跟随。 -
修改连接线路由、箭头和标签。 -
使用网格、对象吸附和智能参考线定位节点。 -
使用对齐和等间距分布整理布局。 - 通过 Layer 管理背景/主流程，通过 Group
组织子流程。

## 页面组织

该演示作为现有 Canvas Gallery 页中的一个可切换
Demo。所有节点、Text、Connector 和 Group 都属于
Document。工具栏、属性面板和 Layer 面板由 Gallery 组合，通过 Canvas 公开
API 操作。

Connector 必须使用真正的端点锚定关系，不能只把连接线画成与节点无关的静态
Path。

## 完成条件与验证

-   初始流程图节点、文字和连接线均为可编辑 Document 项。
-   节点移动/变换后锚定 Connector 更新正确。
-   Connector 箭头、标签、顺序和导出结果正确。
-   网格吸附、对象吸附、锚点吸附、对齐和分布可以组合使用。
-   Group/Layer 操作不破坏连接关系。
-   Gallery 能正常编译。
-   BRP 验证节点拖动、连接端点吸附、文字编辑、排序和
    Undo/Redo，并检查中间与最终 Screenshot。

## 设计边界

不实现自动布局、自动避障或完整流程图语义验证。流程图布局由用户通过连接、吸附、对齐和分布工具完成。
