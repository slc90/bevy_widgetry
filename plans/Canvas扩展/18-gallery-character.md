# Gallery：制作 GPT 龙娘矢量立绘演示

## 目标

使用 GPT 龙娘作为原创角色示例，展示 Canvas 对复杂轮廓、局部部件、嵌套
Group、Layer 和渐变的支持。

## 参考素材

使用打包的 `assets/赛博幻彩龙娘与全息界面.png`
作为角色造型和配色参考。角色的识别特征包括白银色长发、青蓝/蓝紫色龙角、龙尾、科技幻想风服装和轻量全息界面装饰。

参考 PNG 在 Gallery 中作为旁边的参考图显示，不放进 Canvas Document
作为角色主体。GalleryAssetPlugin 按现有 Embedded Asset
方式注册该图，资源属于 Gallery，不迁入 Canvas crate 或通用内建 Asset
crate。

## 矢量作品范围

首版制作头肩/半身矢量形象，优先表现角色识别特征和可编辑结构，不追求逐像素复刻全身立绘。作品由真实
Canvas Shape、Path、Text、Paint、Group 和 Layer API 创建。

建议拆分： - 后发、刘海、侧发和发饰。 - 龙角、耳朵与可见的尾巴局部。 -
脸型、眼睛、眉毛、嘴巴和腮红。 - 服装、领口、袖子和装饰带。 -
科技挂件与全息界面装饰。

Layer 区分背景、后发、主体和前景装饰；Group
组织头部、头发、面部、服装和装饰。渐变用于头发、角、眼睛或服装局部。每个部件都应能独立选择和调整。

## 交互展示

用户可以单独选择刘海、眼睛、龙角或衣服部件，调整颜色、渐变、位置和顺序；也可以选择头部或角色
Group 整体移动、旋转和等比缩放。节点编辑可以修改部分 Path 轮廓。

## 完成条件与验证

-   角色主体由 Canvas 矢量项构成，参考 PNG 仅作为旁边的参考图。
-   角色部件有合理 Layer 和嵌套 Group 结构。
-   局部 Path 可继续节点编辑，部件可独立选择与变换。
-   渐变实际应用于角色部件，并可编辑。
-   SVG/PNG 导出保留角色整体外观。
-   Gallery 能正常编译。
-   BRP 验证部件选择、Group 变换、Layer 顺序和渐变手柄，并通过
    Screenshot 检查整体与局部效果。

## 设计边界

角色 Demo 是 Gallery 的示例作品，不把 GPT 龙娘变成 Canvas crate
的内置业务概念；不引入角色动画、骨骼或位图绘画系统。
