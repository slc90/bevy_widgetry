# 千石冠 Splash｜拆分方案总览

> 这是 **Plan Decomposer** 产生的唯一线性实施序列。拆分原则是重新归类原 `master-plan.md` 的全部正文，而非摘要成任务级 TODO。完整技术论证保留于各阶段详细正文；本文件只做导航。

**目标：** 在 Bevy 0.20 + Windows DX12 的现有 `bevy_widgetry` Gallery 内，以 60 FPS 为目标播放 1 秒千石冠探头/挥手/眨眼，并通过圆形波纹安全揭幕到已经准备好的 Gallery；保留现有日志、GPU 初始化、页面状态和光标流程。

## 唯一顺序

1. **[标准化千石冠角色与背景素材](01-资产标准化与几何拼装.md)** — 取得可以准确重组、可独立运动和完成视觉验收的动画图层；产出：通过的 PNG 图层、layer_map.json、差异预览与素材 QA 报告。
2. **[建立 Bevy UI 离屏合成与全窗覆盖通道](02-离屏静态场景与窗口覆盖.md)** — 让可验收的静态千石冠场景渲染到纹理，再作为 Gallery 主窗口的最上层图像出现；产出：静态 Splash UI 场景、离屏纹理、全窗展示与兜底遮挡验证。
3. **[实现约 1 秒的千石冠实时演出](03-实时角色演出.md)** — 完成时间驱动的探头、挥手、双丝带随动和眨眼并确认 60 FPS 目标的可测性；产出：能多次验证的 0–800ms 角色动画及稳定的交接末姿。
4. **[建立 Splash 资源加载与展示生命周期](04-加载与就绪生命周期.md)** — 确保素材与第一帧真正就绪后再起表，并在 Gallery 未准备好或异常时安全等待/退出；产出：完整 Splash 状态机、时序信号和失败退化约定。
5. **[实现从手掌扩散的圆形波纹揭幕](05-圆形波纹Shader.md)** — 让离屏 Splash 画面从手掌位置开始局部透明并平滑显露真实 Gallery；产出：能在 200ms 内清晰揭幕的 shader 材质、WESL/WGSL asset 和逐时刻画面。
6. **[将完成的 Splash 无侵入接入 Gallery](06-Gallery正式集成.md)** — 实现真实主窗口的一次性 Splash 播放、输入隔离与正确恢复；产出：可启动的 widget_gallery 完整链路，不修改公共控件行为。
7. **[完成 Windows DX12 实机验证与交付验收](07-实机与回归验收.md)** — 用可复现证据确认动画、资源、转场、输入、性能和错误路径达到本轮目标；产出：性能/功能测试记录、未决问题说明、可交付源码及准确完成结论。

严格按照 **01 → 02 → 03 → 04 → 05 → 06 → 07** 顺序推进。相邻文档各承担一个主要目标，**未通过的素材对位、渲染或加载条件不得在下一阶段被静默忽略**。
