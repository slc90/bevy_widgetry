# Gallery i18n 实施方案

## 1. 目标与范围

为 Bevy 0.20 的 `gallery` 增加简体中文与英文实时切换，主要用于验证轻量 i18n 在现有控件和页面中的可用性。

- 仅修改 `gallery`，不修改 `bevy_widgetry`。
- 不引入第三方 i18n 库或外部翻译资源。
- 翻译内容直接编译到可执行文件。
- 默认语言为 `English`，不持久化语言选择。
- 仅翻译面向用户的 UI 文本，不翻译日志、内部调试信息和代码标识符。
- 切换语言不重建页面，不重置已有控件状态。
- 中文字体沿用现有方案。

不以构建通用 i18n 框架为目标。

## 2. 模块组织

使用 Rust 非 `mod.rs` 模块布局：

```text
gallery/src/
├── i18n.rs
└── i18n/
    ├── language.rs
    ├── key.rs
    ├── en_us.rs
    └── zh_cn.rs
```

- `language.rs`：语言枚举。
- `key.rs`：强类型翻译键。
- `en_us.rs`、`zh_cn.rs`：各语言的翻译表。
- `i18n.rs`：统一接口、占位符处理和语言更新机制。

翻译键使用枚举，可通过嵌套枚举按页面或功能分层。层级深度由业务决定。

各语言使用穷尽式 `match`，利用编译器检查翻译键覆盖情况，不使用通配分支掩盖遗漏。

语言文件变大时再进一步按页面拆分。

## 3. 翻译接口

提供：

```rust
tr(language, key) -> &'static str

tr_args(language, key, args) -> String
```

支持命名占位符，例如：

- English：`"{count} items selected"`
- 简体中文：`"已选择 {count} 个项目"`

不同语言可自由调整占位符位置。

缺少参数时，保留未替换的占位符并输出错误日志，不使程序崩溃。

暂不实现复杂复数规则或语言语法引擎。

## 4. 语言切换与 UI 更新

通过 Bevy `Language` Resource 保存当前语言。

静态 UI 文本使用 `LocalizedText` 组件记录翻译键。语言变化后原地更新现有 `Text`，不重建实体。

- 常驻 UI：标题栏、Sidebar 等立即更新。
- 页面 UI：当前页面立即更新，新进入的页面使用当前语言。
- 参数文本：语言变化时重新翻译；业务参数变化时由对应 UI 系统主动刷新。
- 可编辑文本：保留用户输入，不因语言变化覆盖其内容。
- 动态控件：根据控件的数据结构进行适配，不强制使用统一更新机制。

语言变化只影响文本表现，不应触发无关的业务值变更事件。

## 5. 动态文本处理原则

**i18n 负责统一翻译，各页面负责自己的动态数据适配。**

区分两类内容：

| 内容类型 | 处理方式 |
|---|---|
| 预定义的可翻译文本 | 保存 `TextKey`，显示时翻译 |
| 任意运行时字符串 | 保存 `String`，原样显示 |

必要时可以使用：

```rust
enum ItemLabel {
    Localized(TextKey),
    Raw(String),
}
```

例如 ComboBox 的 `Inserted` 是预定义文本，即使运行时才插入，也可以保存对应翻译键。

对于 `Edit selected` 追加的 `*`，单独保存编辑状态，不修改翻译键。

切换语言时更新选项的显示文字，同时保留 Model、Item ID、选中状态和编辑状态。

各页面按实际需要实现更新逻辑。不为所有动态数据预先设计通用绑定框架，也不要求所有动态字符串都参与翻译。

## 6. 语言选择器

在 `gallery/src/header.rs` 中增加语言 ComboBox。

位置为标题栏右侧控制区，位于现有 `scale_factor` ComboBox 左侧。

- 选项：`English`、`简体中文`
- 默认选中：`English`
- 与现有 ComboBox 保持相同视觉风格
- 选择后立即更新界面
- 不增加额外确认操作

现有主题、缩放比例及窗口控制功能保持不变。

## 7. 翻译覆盖范围

覆盖 gallery 中面向用户的可本地化 UI 文本：

- 页面标题、导航名称、描述
- 按钮、标签、菜单、Tooltip
- 应用提供的状态提示和错误提示
- 预定义的动态选项及可翻译的展示数据

技术标识符、API 名称可以保留原文。

用户输入、外部任意数据、日志及内部诊断信息不自动翻译。

## 8. 验收要求

1. 启动时默认英文，重启后仍恢复英文。
2. 中英文切换后，当前页面文本立即更新。
3. 切换不重建页面，不改变滚动位置、焦点、选中项或输入内容。
4. 新进入的页面使用当前语言。
5. 命名占位符正确替换，参数变化后对应显示正确更新。
6. 缺少参数时保留占位符并记录错误日志。
7. ComboBox 的预定义动态选项正确翻译，运行时插入、编辑、删除及重置功能保持正常。
8. 任意字符串数据保持原样，不被误翻译。
9. 中英文翻译键完整，中文显示正常。
10. 日志内容和现有主题、缩放功能不受影响。

## 9. 实现原则

优先保持 i18n 核心小而明确。

对于静态 UI，使用统一的 `LocalizedText` 更新机制；对于动态 UI，按当前页面的数据模型进行针对性处理。

**本次重点是验证 i18n 的实际可用性，而不是消除所有页面适配代码。**

未来只有在不同页面确实反复出现相同需求时，才考虑提取公共机制。
