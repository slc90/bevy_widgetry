# bevy_widgetry 功能完善与新增清单

## 第一部分：现有控件与 Gallery 补强

### 1. Button

- 新增 Link 变体，用于打开外部 URL。
- 新增 Loading 状态，并在加载期间阻止重复点击。
- 新增特殊的游戏风格按钮：红色、圆形、华丽装饰、无文字，具体设计后续讨论。

### 2. TextField

- 新增 `maxLength`：限制最大输入字符数。
- 新增 `showCount`：显示当前输入字符数量。
- 新增 Prefix / Suffix：支持自定义前缀、后缀内容。
- 新增 AutoSize：多行输入时自动调整高度，并支持设置最小、最大行数。
- 新增 Placeholder：未输入内容时显示占位提示。

### 3. ComboBox

- 新增可选的搜索功能，由应用提供选项匹配回调。
- 新增可自定义的无搜索结果提示。
- 新增未选择任何选项时的占位提示。
- 允许应用通过程序主动清除当前选中项。

### 4. ListView

- 默认支持 Ctrl + 点击，切换单个条目的选中状态。
- 默认支持 Shift + 点击，进行连续范围选择。
- 支持 Ctrl + A，选中整个数据模型中所有未禁用的条目，包括尚未渲染的虚拟化条目。
- 新增可选的拖拽排序功能，默认关闭。
- 拖拽排序时只移动实际拖动的单个条目，即使当前存在多选。

### 5. TreeView

- 默认支持 Ctrl + 点击，切换单个节点的选中状态。
- 默认支持 Shift + 点击，进行连续范围选择。
- 支持 Ctrl + A，选中当前可见的全部未禁用节点。
- 节点折叠后保留隐藏子节点的选中状态，重新展开后恢复显示。
- 新增可选的节点拖拽功能，默认关闭。
- 支持通过拖拽调整节点顺序和父子关系。
- 每次只拖动一个节点，并防止产生循环父子关系。
- 节点拖拽功能安排在 ListView 拖拽功能完成后实现。
- 新增全部展开、全部折叠功能，仅作用于已加载节点，不强制触发远程懒加载。
- 展开、折叠操作保留已有的节点选择状态。

### 6. Table

**排序与筛选**

- 表头新增可选的排序入口，排序逻辑由应用实现。
- 表头新增可选的筛选入口，筛选逻辑由应用实现。

**选择功能**

- 支持选择单元格、整行和整列。
- 支持 Shift + 点击扩展连续选择区域。
- 支持鼠标拖动形成矩形选择区域。
- 同一时间维护一个连续选择区域。
- 支持 Ctrl + A 选中整个数据模型，包括未渲染的虚拟化内容。
- 支持点击表格左上角区域进行全选。

**单元格编辑**

- 新增可选的单元格编辑功能。
- 支持为不同的强类型数据分别注册对应编辑器。
- 支持 F2 或双击进入编辑。
- 支持 Enter 确认、Esc 取消。
- 数据验证由应用负责。

**剪贴板**

- 支持 Ctrl + C 复制当前选择区域。
- 复制内容采用 TSV 格式。
- 支持为不同的强类型数据分别注册复制格式化器。

**冻结列**

- 支持冻结最前面的 N 列，默认 N = 0。

**列拖拽**

- 新增可选的列拖拽排序功能，默认关闭。
- 通过拖动列标题调整列顺序。
- 区分列拖拽区域与列宽调整区域。
- 保持冻结列与非冻结列的区域边界。

**行拖拽**

- 新增可选的行拖拽排序功能，默认关闭。
- 通过行号区域进行拖拽。
- 每次只移动一行，即使当前选中了多行。

### 7. Window

- 双击标题栏空白区域时，在普通窗口与最大化窗口之间切换。
- 仅在窗口允许最大化时生效。
- 作为默认交互行为，无须额外配置。

### 8. Waveform

- 列入专项补强范围。
- 具体需要完善的功能和调整内容，后续单独讨论确定。

### 9. Cursor

- 完善 Kamuri 主题的光标动画。目前主要是 Pointer 和 Wait 具备动画，其余光标需要进一步检查。
- 统一不同光标的视觉尺寸和缩放比例，改善整体一致性。
- 具体动画调整范围及尺寸方案，后续单独讨论。

### 10. Gallery Splash

- 对 Gallery 现有 Splash 启动画面进行整体精装修。
- 重点提升视觉效果、动画表现和整体完成度。
- 重新检查并调整 Splash 使用的 Kamuri 动画。
- 与 `crates/` 下的通用控件补强分开，作为 Gallery 专项处理。

## 第二部分：新增 UI 控件

### 1. Segmented

分段式互斥选择控件，用于在少量选项之间快速切换。

### 2. Tabs

标签页控件，用于在多个内容页面之间切换。

### 3. Slider

滑动条控件，用于通过拖动直接调整数值。与 ProgressBar 尽可能复用底层基础代码。

### 4. ProgressBar

进度条控件，用于展示任务完成进度。与 Slider 保持独立控件语义，同时复用能够共享的底层能力。

### 5. Splitter

可拖拽分隔面板控件，用于调整相邻内容面板的大小。

### 6. NumberInput / SpinBox

数值输入控件，用于整数、浮点数等数值输入场景。

### 7. ColorPicker

颜色选择控件，用于 GUI 软件中的颜色选择与编辑，可参考 Ant Design 和 Bevy Feathers。

### 8. DatePicker

日期选择控件，用于通过日历界面选择日期。

### 9. Collapsible

可折叠内容面板，用于展开、收起一组内容，适用于设置页面、侧边栏和分组内容等场景。

### 10. Canvas

- 新增类似 HTML Canvas 的程序控制式二维绘图控件。
- 基于 Bevy 现有的 `ViewportNode` 和 `Mesh2d` 等渲染能力构建。
- 支持绘制矩形、圆形、线条、路径、文本等二维内容，具体范围后续确定。
- 作为普通 UI 控件参与布局，并支持随布局调整绘图区域尺寸。
- 处理绘图区域裁剪及 UI 与画布之间的坐标转换。
- 提供适合 GUI 软件使用的绘图抽象，不重新开发底层渲染引擎。

### 11. Password

- 新增独立的密码输入控件，不再作为 TextField 的一种模式。
- 复用 TextField 现有的文本输入和编辑基础能力。
- 默认以掩码形式显示密码内容。
- 支持切换密码内容的显示与隐藏。
- 具体复用方式与控件接口后续单独讨论。

## 第三部分：新增非 UI 功能

### 1. 系统托盘图标（System Tray）

新增 Windows 系统托盘图标支持，提供桌面 GUI 软件所需的系统托盘集成能力。

具体功能范围和实现方案后续专项讨论。

### 2. 统一 Job 管理系统

- 新增集中式 Job 管理系统，用于统一管理异步任务和并行任务。
- 解决目前 Bevy Task 使用较为分散、缺乏统一管理的问题。
- 目标是完整的任务生命周期管理，而不只是提供统一的任务提交入口。
- 基于 Bevy 现有任务执行能力，不另行开发一套新的异步运行时或线程池。
- 具体管理能力、功能边界和实现方案后续专项讨论确定。
