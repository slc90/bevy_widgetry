# Table 强类型格式化与完整 View TSV 复制

Table 的 Cell Renderer 可以生成任意 UI，不保证其视觉文本能够还原强类型业务值。因此复制不能抓取已经生成的 UI 文本或屏幕像素，而应根据当前 View 的逻辑选择范围、稳定 ID 和独立的强类型复制格式化器生成 TSV。复制与虚拟化解耦：没有实例化的 Cell 仍应参与用户选中的整行、整列、矩形及 Ctrl+A 结果。

## 复制格式化器与取值路径

按 Cell 值类型注册**默认复制格式化器**，并允许按 `ColumnId` 覆盖，解析优先级为“列覆盖 → 值类型默认”。格式化器接收相应强类型值，输出普通 `String`。它与 Cell Renderer、Header Renderer 以及强类型 Editor 注册表相互独立；同一个业务值可按列分别输出不同文本（例如金额列、数量列），不要求和视觉 UI 完全相同。Table 以稳定 `(RowId, ColumnId)` 从共享 Model 投影原始值，再由格式化器输出字符串，不能默认使用 `Debug` 字符串或尝试解析 Renderer 子树。

复制时先在逻辑层冻结/读取当前选择范围对应的 RowId 和 ColumnId 顺序，再生成二维文本。行顺序严格使用**当前 View 显示顺序**，列顺序使用当前 View 的显示顺序；过滤掉的行不参与，但被二维虚拟化而暂时没有 Cell Entity 的项目必须参与。普通单格、行选区、列选区、矩形选区和角落/Ctrl+A 全选均复用同一范围解析与格式化流程。

## 快捷键归属与表头边界

`Ctrl+C` 仅在 Table 普通选择状态下复制完整的所选区域。进入原位编辑器后，快捷键归编辑器所有：例如 TextField 内部 Ctrl+C 应复制用户在输入框选中的文本，不触发 Table 整行或矩形复制。无逻辑选择时不应因为焦点在 Table 就擅自复制全部内容。

复制**只包含实际数据**。无论整行、整列还是 Ctrl+A 和角落全选，都不写入列标题、行号及左上角 Corner 的标签；排序/过滤图标、冻结列占位也不产生额外字段。输出采用 Tab 分列，记录之间用换行分隔的 TSV。

## 不改变数据的 TSV 序列化

格式化器输出的字符串是原始单元格文本，Table 负责最终 TSV 转义。普通字段直接输出；含 Tab、实际换行（包括 CR/LF）或双引号的字段用双引号包围，字段中的每个 `"` 序列化为 `""`。这是为了在支持带引号 TSV 的表格软件中保持每个原始单元格的边界，**不把真实换行替换成字面上的 `\\n`，不删除制表符，不修剪值**。

例如备注值含有真实换行：

```tsv
001	"第一行备注
第二行备注"	已完成
002	普通备注	进行中
```

第一条记录仍是三列；引号只属于序列化表示，目标表格软件可解析回原始字段。简单地按 `\n`、Tab 拆分且不支持引号语义的 TSV 消费者可能无法正确还原多行字段，此限制不应成为静默改写原始数据的理由。

## Gallery、文档与完成条件

`gallery/src/pages/table.rs` 为多强类型列注册格式化器，展示列覆盖、自定义金额/状态等格式、矩形跨离屏复制、整行/整列和 Ctrl+A、同一个 Model 的不同 View 显示顺序复制结果不同、编辑器内部 Ctrl+C 不触发 Table。加入至少一格带真实 Tab、换行和 `"` 的备注，并通过 Gallery 中英文说明告诉调用方复制保留单元格内容且不附加表头；可以附带供用户粘贴到外部软件核对的可见示例，并通过可控制的未注册格式化器场景展示明确失败且不覆盖既有剪贴板内容。

`crates/table/tests/interaction.rs` 及必要 clipboard 测试覆盖选择种类、输出顺序、虚拟化跨窗口、不包含过滤行、不包含 Header、强类型默认和列覆盖、编辑器快捷键拥有权、字段转义与双引号往返、空投影和撤销编辑后恢复 Ctrl+C；还要覆盖缺失格式化器、格式化错误及读值失败时整体拒绝，断言没有调用剪贴板写入入口、旧剪贴板内容保持不变，并能定位失败单元格。同步 `docs/crates/table.md`、`tests/COVERAGE.md`，并回归 Table 与 TextField 的焦点/输入分派。

## 整体复制成功或失败

复制过程遵守**全选区原子提交**：先解析完整逻辑选区，再对选区内全部 `(RowId, ColumnId)` 逐个获取强类型值、按“列覆盖 → 类型默认”解析格式化器并生成文本，全部成功后完成 TSV 序列化；**只有所有字段成功，才一次性写入系统剪贴板**。单元格格式化过程及 TSV 拼装过程中不能提前把部分结果写入剪贴板。

任何一个单元格缺少可用格式化器、格式化返回错误，或读值/序列化失败，都让本次复制整体失败，明确向调用方报告错误，**不修改原有剪贴板内容**。不允许把失败字段变为空字符串、略过列/行、使用 `Debug` 字符串或从 Renderer 子树抓取替代文本。失败需要包含足以定位问题的单元格稳定身份与失败原因；具体错误类型保持与现有项目错误风格一致，不强制另造一套错误框架。

例如一次复制 100 个单元格，第 68 个没有匹配的列覆盖或类型默认格式化器，前 67 个已生成的文本也只停留在暂存结果中；本次不产生 TSV 剪贴板写入。调用方补齐格式化器后可再次 Ctrl+C，仍以当时 View 的实际投影和选区为准。
