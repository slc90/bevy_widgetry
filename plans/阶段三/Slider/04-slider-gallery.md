# Slider Gallery 展示

## 目标与设计思路

在现有 Gallery 中增加 Slider 页面，让用户在真实场景下体验前面已交付的控件能力。该页面不是静态图或另一套 Slider 实现：使用 Widgetry 的 BSN 直接构造实际 Slider，并通过控件外的 Text 呈现实时 `value`，使输入效果可观察。

Gallery 继续使用原有的常驻框架与按需挂载页面结构；切换离开时清理页面内 Slider 和展示状态，重新进入时创建新的演示，不将临时值保存为全局持久数据。

## 演示内容

| 场景 | 展示与验证重点 |
| --- | --- |
| 水平连续 Slider | `step = None` 时连续拖动与左右方向键 |
| 水平步进 Slider | `min = 0, max = 10, step = 3`，检查正向、反向步进以及端点 |
| 垂直 Slider | 下方是 `min`，上方是 `max`；蓝色等已填充段从下向上延伸，支持上下方向键 |
| Disabled Slider | 禁用态外观、当前位置保留及用户输入不生效 |
| 默认尺寸对照 | Track `6px`、Thumb `20px` |
| 自定义尺寸对照 | Track `10px`、Thumb `28px`，通过 BSN Props 覆盖 |

尺寸对照不只是静态展示，也应允许实际操作，从而观察修改轨道和 Thumb 尺寸后的定位、移动范围、命中区域和拖动手感。默认与自定义实例可以沿用上述功能场景组合，不必为每个效果额外创建互不相关的演示逻辑。

## 实时数值显示

每个可交互 Slider 旁边放置一个 Gallery 自己构造的 `Text`。例如从 `3` 拖到 `6` 时，显示文本同步由 `3` 更新到 `6`。数据来自 Slider 的值和变化通知，监听 `ValueChange<f32>`，不将这个标签加入控件内部，也不为演示复制第二套交互状态。

不额外提供“重置到 min”按钮；本页集中展示直接操作与实时反馈。步进示例能够直接观察 `0 → 3 → 6 → 9 → 10` 和 `10 → 7 → 4 → 1 → 0` 的方向差异。

## 与 Gallery 现有机制集成

按照当前导航和页面组织新增 Slider 独立入口。页面说明、场景标签纳入 English / 简体中文国际化；复用 Gallery 既有 Theme、Scale Factor 切换及页面生命周期。Theme 改变时实际 Slider 颜色随之刷新，Scale Factor 改变时布局与命中位置仍相符。

Gallery 通过顶层 Facade 导入 Slider 的公共类型及 Plugin。前序增量相应的 Workspace crate、Facade Feature、Theme 接入和文档更改在各自增量中完成；本页只引入展示所需的应用内代码和文案，不反向改变 Slider 的状态契约。

## 完成条件与验证

Gallery 页面能构建、导航、进入、离开和再次进入。实际拖动或键盘操作时，旁侧文字应跟随真实 `ValueChange<f32>` 更新；Disabled 示例应拒绝用户输入。垂直填充方向、双向步进、自定义尺寸的几何表现都应可以直观看到。

在现有 Theme（包括不同颜色主题）、中英文和 Scale Factor 条件下检查排版、值显示、拖动和焦点状态。按仓库已有要求编译 Gallery，并用 GUI / BRP 方式验证受影响的可观察行为；BRP 指针输入不能完全代替真实 Mouse 的输入验证。同步更新 Gallery 的导航及功能文档，以及必要的 Slider crate / 架构文档关联内容。
